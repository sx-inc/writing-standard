# 文章の判断基準

書くとき・直すときに照らす判断基準。層A（読み手を問わず）／層B（画面の前で操作する読み手）／
層C（画面・組版・配布物まで自分で作るとき）の 3 層。

- 使い方: プロジェクトの `CLAUDE.md` に `文章: /文章の判断基準.md の 層A を適用する` の 1 行を置く。
  宣言が無いプロジェクトでは層A だけを適用する。
